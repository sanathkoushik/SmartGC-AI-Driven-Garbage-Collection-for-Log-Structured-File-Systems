## The pipeline

```
Real block-I/O trace (MSR Cambridge 2007 / SYSTOR 17, 2016)
      |  parse, validate, expand every request to 4KB blocks
      v
Normalized trace       timestamp,lba,size,operation,trace_id
      |  per-LBA gaps between consecutive writes
      v
Rewrite intervals      (first write of an LBA yields no target)
      |  sliding windows, chronological 70/15/15 split
      v
Sequences              L intervals -> the next interval
      |  pooled over pretraining workloads, targets held out
      v
Pretrained LSTM        models/pretrained/msr_pretrained.pt
      |  adapted on the target's EARLY training split only
      v
Fine-tuned LSTM        models/finetuned/*.pt
      |  scored on every predictable write
      v
Predictions            timestamp,lba,interval,class,model,trace
      |  threshold from TRAINING targets only
      v
Hot/cold labels        -> main log or cold log
      |
      v
C++17 LFS simulator    greedy cleaning, dedicated GC append point
      |  physical / logical bytes
      v
WAF, valid-block migrations, GC invocations
```
